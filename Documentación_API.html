Integración Full-Stack

Conecta el motor de optimización de grado militar directamente a tu infraestructura. Ideal para procesar catálogos en plataformas SaaS y aplicaciones E-commerce.

Autenticación

Para interactuar con la API, debes incluir tu API Key en las cabeceras de cada petición. Puedes copiarla desde tu panel de usuario.

// Petición HTTP (Header)
Authorization: Bearer CPLY-TU-API-KEY-AQUI

Endpoint R2 Automático

El flujo Procesar y Olvidar. Envías la imagen original, nosotros la comprimimos a WebP y la alojamos permanentemente en nuestros servidores Cloudflare R2 (Cero costos de almacenamiento para ti).

Caso de Uso: Tiendas Online (WhaShopping)

Cuando un cliente sube una foto de producto, envíala a la API. Devuelve una URL superligera lista para insertar en la base de datos de tu catálogo.

Ejemplo de Petición (Node.js) POST /v1/optimize 
const response = await fetch('https://api.compressly.com/v1/optimize', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer CPLY-XXXXX',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    image_base64: "data:image/jpeg;base64,/9j/4AAQSkZJR...",
    target_format: "webp",
    max_width: 1200,
    project_tag: "whashopping-catalog" // Etiqueta de organización
  })
});
Respuesta Exitosa (JSON) 200 OK 
{
  "status": "success",
  "data": {
    "hosted_url": "https://cdn.compressly.com/r2/whashopping-catalog/img_9821.webp",
    "original_size_kb": 4500,
    "compressed_size_kb": 125,
    "savings_percent": 97.2
  }
}

Implementación en Portafolios (Linkea)

Si administras perfiles de usuarios (como en el ecosistema Linkea), puedes usar el parámetro quality: 80 y max_width: 400 para avatares. Tu servidor solo recibirá la hosted_url, manteniendo tu base de datos extremadamente limpia y tus páginas cargando en milisegundos.
